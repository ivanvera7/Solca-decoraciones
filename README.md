# SOLCA Decoraciones

Pagina Web Para una empresa de Decoraciones en Paraguay ⭐️

Web: https://solca-decoraciones.vercel.app

## Desarrollo

Requiere Node 24 (`.nvmrc`) y npm.

```bash
npm ci
npm run dev     # http://localhost:3000
npm run check   # lint + tipos + tests
npm run build
```
